# RawPackages

Yahan apni downloaded `.unitypackage` files daal do (Unity Asset Store se) — jaise
`LowPolyJungle.unitypackage`, `LowPolyWolf.unitypackage`.

GitHub Actions build se pehle inhe automatically `Assets/` me extract kar dega
(dekhen `.github/workflows/android-build.yml`).

FBX files (Mixamo, Sketchfab se) yahan mat daalo — unhe seedha
`Assets/Models/` folder me daalo, unhe extraction ki zarurat nahi hai.
